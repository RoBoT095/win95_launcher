# Changelog

## v2.0.0

- Added option in settings to clear specific or all renamed apps
- Added app icon toggle for home and drawer screens as well as controls for app icon size
  - Toggle for pixelation amount that shrinks and resizes images for pixel look
- Fixed scroll up not exiting to home screen until scrolling down a bit first
- Fixed rendering/overflow issues with larger fonts in different orientations
- Fixed home and app list not updating if app has been installed or uninstalled

## v1.1.0

- Added option to rename apps from app list on long press
- Fixed home app shortcut apps set to center bottom alignment not aligning to the bottom
- Added battery indicator to home header
- Keyboard dismisses when scrolling in app list
- Added option to lock rotation to portrait
- Home screen apps split into 2 columns on landscape orientation
- App list search now ignores most common special characters
- Updated about page
